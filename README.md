# Safelight Print Mat — discontinued

**Print Mat is discontinued.** It no longer frames photos on export or in Develop.

Please **deactivate and uninstall** this extension in Safelight → **View → Extensions**, then install the replacement:

```
OPGERUIMD97/safelight-mat-frame
```

[Mat/Frame](https://github.com/OPGERUIMD97/safelight-mat-frame) is the v2 module: dedicated tab, Filmstrip + Export docked, framing only while that module is open.

Your saved Print Mat templates stay in browser storage under `safelight-print-mat-*` so Mat/Frame can import them.

## Changelog
